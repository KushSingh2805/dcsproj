# Comparison-of-High-Order-Conv.QAM-to-GS.QAM
MATLAB-based performance analysis of geometrically shaped high-order QAM over AWGN, Rayleigh, and Rician 5G wireless channels. The project compares conventional and geometrically shaped 64-QAM, 256-QAM, and 1024-QAM using BER, SER, and EVM to evaluate shaping gains under different channel conditions.
